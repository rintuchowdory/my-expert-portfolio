# **App Name**: ProFolio Connect

## Core Features:

- Project Showcase: Visually rich display of past projects with descriptions, imagery/videos, and direct links to live demos and GitHub repositories.
- About Me & Professional Bio: A dedicated section detailing professional experience, skills summary, and personal career narrative.
- Skills & Technologies: Categorized presentation of technical skills, programming languages, frameworks, and tools proficiency.
- AI-Powered Project Storyteller: An internal tool to assist the portfolio owner in crafting varied, audience-specific narratives and summaries for each project based on provided technical details and impact statements.
- Contact & Inquiry Form: A functional contact form enabling potential employers or collaborators to send direct messages, leveraging a simple external email service.
- Downloadable CV/Resume: A prominent link to download a professional PDF version of the developer's curriculum vitae.

## Style Guidelines:

- Color scheme: Dark theme, chosen to convey modern sophistication and allow content to stand out. The base color hue reflects professionalism and innovation.
- Background color: A deep, muted slate blue for the primary background (#1A1E24).
- Primary accent color: A vibrant yet refined blue for interactive elements, headlines, and key highlights (#3F86E6).
- Secondary accent color: A contrasting energetic cyan for call-to-action elements and visual differentiation (#70D6EE).
- Headline font: 'Space Grotesk' (sans-serif) for a modern, slightly tech-inspired aesthetic, suitable for impactful titles.
- Body font: 'Inter' (sans-serif) for clean readability and versatile use across project descriptions and general content.
- Use a set of minimalist, line-art icons that maintain a professional and clean aesthetic, consistent in stroke weight and style throughout the application.
- Employ a responsive, grid-based layout for projects, featuring generous spacing and a balanced, asymmetric composition to highlight individual works effectively on all device sizes.
- Integrate subtle, smooth animations for element transitions (e.g., fade-in on scroll, hover effects on project cards), providing a dynamic and premium user experience without distraction.
